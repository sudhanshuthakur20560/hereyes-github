Internet & Web Technology (IWT) Quiz

Answer the 6 basic questions below, then check your answers in the final section.

1. What does HTTP stand for?

2. Which protocol translates domain names (e.g., google.com) into numerical IP addresses?

3. In HTML, which tag is used to create a hyperlink to another web page?

4. What is the standard default port for secure HTTPS traffic?

5. Which HTTP status code indicates that the requested page was not found?

6. In the CSS Box Model, which property creates space INSIDE an element's border?

View Answer Key & Explanations
  • Q1 Option B — HyperText Transfer Protocol: The foundational application protocol used across the World Wide Web.
  • Q2 Option C — DNS (Domain Name System): Resolves human-friendly domain names to machine-readable IP addresses.
  • Q3 Option B — <a> (Anchor): Creates hyperlinks using the href attribute. (Note: <link> is for linking external stylesheets).
  • Q4 Option C — Port 443: Standard port for encrypted HTTPS traffic. Unencrypted HTTP uses port 80.
  • Q5 Option B — 404 Not Found: The client contacted the server, but the requested resource does not exist.
  • Q6 Option B — padding: In the CSS Box Model, padding creates space inside the border, while margin creates space outside.
