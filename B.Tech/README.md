## 📑 Subject Breakdown

### 1. IWT — Internet & Web Technology
- **Introduction to Web Technologies (Unit 1)** (`.docx` & `.pdf`)
- **CSS Architecture & Styling**: CSS Box Model, CSS Selectors, Responsive Styling
- **Web Design & UX**: UI/UX Principles, Meta Tags, Favicon & First-Year Basic SEO
- **Forms & DOM**: Registration Form specification, Web Technologies overview
- **Interactive Quizzes**: HTML5 Mock tests & interactive self-testing portals

### 2. FCS — Fundamentals of Computer Science
- **Exam Preparation**: Comprehensive exam preparation guide & Fundamentals by P.K. Sinha
- **Operating Systems**: OS generations, process memory layout (`sbrk`), system performance profiling (`vmstat`)
- **Hardware Architecture**: Memory hierarchy, registers, solid-state drives (SSD), hard disk drive secondary storage
- **Linux Mastery**: Core Unix/Linux CLI utilities, file operations (`cp`, `mv`, permissions), user status commands, C programming on Linux

### 3. SPC — Structured Programming Concepts
- **Core C Constructs**: Loops (for, while, do-while iterative statements), branching, syntax
- **Modular Programming**: User-defined functions, recursion, parameter passing, return semantics
- **Assessment Questions**: Function practice challenges and coding test preparation

### 4. Questions & Assessments (Chitkara Testpad)
- **Practice Test 21 (26CS001)**:
  1. *Alphabetic Seat Allocation System* (Triangular alphabetical layout generation in C)
  2. *Employee Working Hours Analysis System* (Work duration & shift evaluation)
  3. *Electricity Consumption Calculator* (`checkConsumption(units)` with base meter fee & tiered tariffs)
  4. *Temperature Readings Classifier* (Categorizing hot, cold, and zero temperature arrays)
- **Mathematics & Mock Banks**: Partial derivatives question banks and mock tests
